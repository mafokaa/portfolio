# Портфолио Марии Феоктистовой

Сайт на [Astro](https://astro.build). После каждого коммита в `main` Vercel сам собирает и выкладывает сайт.

## Где что лежит

| Что | Где |
|---|---|
| Имя, тексты «Обо мне», контакты, разделы | `src/data/site.ts` |
| Фото первого экрана, «Обо мне», предметы в контактах | `src/assets/site/` |
| Проекты | `src/content/projects/<раздел>/<проект>/` |

Разделы: `branding`, `packaging`, `marketplaces`, `smm`, `uxui`.

## Проект

Каждый проект — это папка с файлом `index.md` и картинками рядом:

```
src/content/projects/branding/aura-bare/
  index.md
  cover.webp
  01.webp
  02.webp
```

`index.md`:

```yaml
---
title: Aura Bare
order: 1                 # порядок в разделе
cover: ./cover.webp      # обложка 16:9
desc: "Кратко — под обложкой на главной"
task: "Кратко — под обложкой на главной"
descFull: "Подробно — на странице проекта (можно не писать)"
taskFull: "Подробно — на странице проекта (можно не писать)"
frames:                  # кадры на странице проекта, сверху вниз
  - ./01.webp
  - ./02.webp
  - video: https://player.vimeo.com/external/....mp4
draft: true              # скрыть проект, пока он не готов
---
```

Для маркетплейсов вместо `frames` — карточки:

```yaml
cards:
  - before: 2.4          # CTR до, %
    after: 6.1           # CTR после, %
    slides: [./card1-1.webp, ./card1-2.webp]
```

Новый проект — скопируйте папку соседнего проекта, переименуйте и поменяйте тексты и картинки.

## Фотографии

1. Положите фото (jpg, png, webp) в папку проекта.
2. Сожмите их:
   ```bash
   npm run images
   ```
   Скрипт уменьшит их до 2400 px по длинной стороне, переведёт в WebP и сам поправит пути в `index.md`. Исходники уйдут в `_archive/originals/` — эта папка в репозиторий не попадает.
3. При сборке Astro ещё нарежет версии под разные экраны, так что телефону не придётся грузить большие файлы.

Видео в репозиторий не кладите — выложите на Vimeo/YouTube и вставьте ссылку.

## Запуск на компьютере

```bash
npm install
npm run dev
```

Сайт откроется на http://localhost:4321.
